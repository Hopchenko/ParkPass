# parkpass-web

The ParkPass web app — Next.js (App Router) + TypeScript + Tailwind 4 + next-intl.

See the [repo README](../README.md) for what ParkPass is, how to run it, and the
project structure, and [docs/PLAN.md](../docs/PLAN.md) for the product plan.

```bash
npm install
npm run dev          # http://localhost:3000
npm run build        # production build
npm run lint         # eslint
npm run check:links  # verify the 62 official park links still resolve
npm run build:pins   # rebuild public/pins/*.webp from ../pin-images/
```
